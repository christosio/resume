Christos Ioannides — accessible portfolio redesign

Extract this ZIP into the document root of christosio.uk (often public_html). index.html, css/, js/, img/ and cv/ must all be directly beside each other there. Do not leave them inside an extra portfolio-accessible/ folder. Open index.html locally to preview. No build tools are needed. If you see unstyled text after upload, verify that https://christosio.uk/css/styles.css loads as CSS, then hard refresh with Ctrl+F5.

Contact buttons use the Messenger and LinkedIn destinations from your original website. The original contact form had no submission endpoint, so this version uses working contact links. The Work section displays the six supplied portfolio images without claiming they are linked projects.

Review the education details, CV, and Astana and Pilsen text before publishing. Those details came from the supplied ZIP. Google Fonts are optional; system fallbacks render if offline.
